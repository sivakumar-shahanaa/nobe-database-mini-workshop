Workshop files

  • create_tables.sql — creates the puzzle tables.
  • policies.sql — allows the leaderboard to be read/written safely.
  • run_sql_functions.sql — creates safe SQL RPC functions for the UI.
  • index.html — the participant-facing workshop page.

Mission brief

  1. Choose a team name and begin the case.
  2. Query only the tables related to your team.
  3. Use SELECT for reads and INSERT / UPDATE / DELETE for modifications.
  4. Submit the final code after you crack the case.
